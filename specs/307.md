# Desktop-only web-интерфейс

## Контекст

Текущий Nuxt-фронтенд предназначен только для desktop web. Мобильный интерфейс
позднее будет реализован отдельным нативным приложением, поэтому поддержка
отдельных responsive-сценариев ниже 768 CSS-пикселей больше не нужна.

## Требования

- Зафиксировать минимальную поддерживаемую ширину web-интерфейса 768
  CSS-пикселей в `AGENTS.md`, `frontend/AGENTS.md` и корневом README.
- Удалить отдельные mobile-only навигацию, drawer, карточки, таблицы,
  пагинацию и CSS/media query для ширины ниже 768 пикселей.
- Сохранить адаптацию desktop-компоновки внутри диапазона 768+.
- Зафиксировать будущий мобильный клиент как отдельное нативное приложение.

## Критерии готовности

- Nuxt использует минимальную layout-ширину 768 CSS-пикселей.
- В затронутых сценариях отсутствуют отдельные mobile-only ветки интерфейса.
- Архитектурный тест запрещает ручные media query ниже 768 пикселей и возврат
  отдельных мобильных меню или drawer.
- Production-сборка, архитектурные тесты и browser smoke на 768 и 1440
  пикселях проходят.
