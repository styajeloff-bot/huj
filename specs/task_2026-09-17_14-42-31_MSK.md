В используемой формой команде назначения есть отдельное несоответствие: проверка склада получает только ID связанных дилеров, без ID самого дистрибьютора. Поэтому обычный сценарий назначения со своего склада не проходит эту проверку, а со склада связанного дилера допускается. Условие показа кнопки в деталях сейчас проверяет только роль дистрибьютора.

## Что требуется изменить

### 1. Довести отбор до п. 2.3 ТЗ

- Сохранить показ заявок своего склада независимо от марки и назначения дилера — п. 2.2.
- Для дилерских автомобилей требовать одновременно членство дилера в **активной группе** активного дистрибьютора и наличие марки автомобиля в его **активных марках**. Сопоставлять `Vehicle.mark_id` с `DistributorBrand.brand_id`.
- Прямая связь с дилером без активной группы и общее поле дилера заявки не должны обходить эти условия.
- Применять одинаковое правило к списку и деталям. В смешанной заявке достаточно одной подходящей позиции; существующую фильтрацию остальных позиций сохранить и дополнить проверкой марки. Несколько оснований доступа не создают повторную карточку.
- Изменение отбора применяется к роли `distributor`; доступ администратора сохраняется — п. 2.6.

### 2. Добавить блок «Дилеры заявки» — п. 2.5 с согласованными изменениями

- На карточке **в списке заявок** показать название и ИНН каждого дилера, относящиеся к нему автомобили и количество.
- Для автомобиля на складе дилера показывать владельца склада. Назначать ему другого дилера через новую форму нельзя.
- Для автомобилей на складе активного дистрибьютора показывать уже сохранённое распределение и неназначенный остаток. Свой склад сам по себе не означает «Дилер не назначен».
- Пока есть неназначенный остаток своего склада, показывать кнопку **«Назначить дилера»**. После полного распределения скрывать её.
- В деталях заявки показывать то же распределение; заменить прежнее безусловное предложение назначить дилера каждой позиции.

Название во множественном числе, выбор автомобилей и количества, распределение только своего склада — уточнения пользователя. Удаление элементов по «красным крестикам» исключено по его решению.

### 3. Расширить существующее назначение до распределения количества

- В форме выбрать одного доступного дистрибьютору дилера, одну или несколько позиций **этой заявки** и количество по каждой. Использовать существующий список связанных дилеров и проверку доступности выбранного дилера.
- Предлагать только неназначенное количество автомобилей со склада активной компании-дистрибьютора. Проверять принадлежность склада и остаток также на сервере.
- Разрешить распределять одну позицию частями между разными дилерами. Например: из 5 автомобилей назначить 2 дилеру А, затем 1 дилеру Б; оставить 2 неназначенными.
- Расширить хранение и API для связей «позиция — дилер — количество». Одного `application_vehicles.dealer_company_id` недостаточно. Сохранённое назначение всей позиции учитывать как назначение всего её количества.
- Количество — положительное целое, не больше неназначенного остатка. Повторные или одновременные операции не должны распределять одни и те же единицы дважды.
- Назначение сохраняет прежние распределения, общее количество, стоимость и физический склад автомобилей. Не создавать дополнительные коммерческие строки, увеличивающие состав заявки.
- Адаптировать существующий доступ по назначенному дилеру к распределённому количеству: каждый дилер получает свою часть позиции, а дистрибьютор сохраняет доступ к автомобилям своего склада.

## Критерии готовности

Серверные правила проверить тестами, взаимодействие с карточкой и формой — в браузере.

- Свой склад виден без дилера и после назначения. Для дилерского склада проверены все сочетания членства в активной группе и совпадения активной марки; заявка видна только при выполнении обоих условий.
- Один дилер в нескольких группах не создаёт дубли. Смена активной компании меняет область заявок. Список и детали согласованы; администратор сохраняет прежний доступ.
- Заявка с автомобилями разных дилерских складов показывает соответствующих дилеров с ИНН; эти автомобили недоступны для распределения.
- Для позиции своего склада из 5 единиц можно сохранить распределение 2 + 1 разным дилерам, затем назначить оставшиеся 2. После перезагрузки распределение сохраняется, остаток равен нулю, кнопка скрыта, исходные количество и сумма не изменились.
- Можно за одно назначение выбрать несколько позиций. Сервер отклоняет чужой склад, недоступного дилера, неверное количество и превышение остатка; каждый назначенный дилер получает только свою часть.
