# Bitrix #21608 — исключить аванс из процентов по лизингу

- **Статус:** согласовано к выполнению
- **Задача:** https://carcraftpro.bitrix24.ru/workgroups/group/124/tasks/task/view/21608/
- **Ветка:** `bugfix/21608-refresh`

## Текущее поведение

В актуальной ветке `test` поле `total_interest` рассчитывается как разница между общей стоимостью и стоимостью договора. Поскольку общая стоимость уже включает аванс, аванс ошибочно попадает в проценты. На примере задачи при авансе 374 000 ₽ проценты завышаются на 374 000 ₽.

## Требуемое поведение

Во всех серверных сценариях расчёта и пересчёта лизингового КП использовать правило:

`проценты = общая стоимость − стоимость договора − аванс`.

Аванс остаётся частью общей стоимости платежей, но не является процентами и не влияет на `markup`.

## Бизнес-цель

Показывать клиенту и лизинговой компании корректную переплату по договору без включения первоначального взноса.

## Изменения

1. Обновить расчёт калькулятора и нормализацию сохранённых предварительных и итоговых КП.
2. Добавить доменную и интеграционные регрессии для ненулевого аванса, частичного обновления и полной оплаты авансом.
3. Подтвердить, что UI выводит поле процентов из API без собственной формулы.

## Критерии приёмки

- При стоимости договора 2 200 000 ₽, общей стоимости 3 735 025 ₽ и авансе 374 000 ₽ API возвращает проценты 1 161 025 ₽.
- При частичном обновлении КП сохранённый аванс также вычитается из процентов.
- При полной оплате авансом проценты равны нулю.
- Фронтенд не пересчитывает проценты самостоятельно.
- Целевые и обязательные backend-проверки проходят.
