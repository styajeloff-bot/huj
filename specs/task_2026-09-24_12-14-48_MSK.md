# Скрыть раздел «Профиль» для carcraft_employee

**Задача:** внутренняя  
**Ветка:** `feature/hide-employee-profile`

## Постановка

Для пользователей с ролью `carcraft_employee` необходимо скрыть раздел
«Профиль» (`/workspace/profile`) из навигации рабочего кабинета и заблокировать
прямой доступ по URL.

## Требования

1. Пункт «Профиль» не отображается в боковом меню для `carcraft_employee`.
2. Прямой переход по `/workspace/profile` для `carcraft_employee` выполняет
   редирект на первый доступный раздел.
3. Для ролей `dealer`, `distributor`, `leasing_company` поведение не меняется.

## Планируемые изменения

### 1. `frontend/features/workspace/config/menu.ts`

Убрать `profileItem` из массива `WORKSPACE_MENU.carcraft_employee` (строка 66).

### 2. `frontend/pages/workspace/profile.vue`

Добавить проверку: если `authStore.isCarCraftEmployee`, выполнить
`navigateTo('/workspace')` (или первый доступный маршрут).

### 3. `frontend/features/auth/components/UserDropdown.vue`

Скрыть ссылку «Профиль» в выпадающем меню пользователя для `carcraft_employee`.

### 4. `frontend/features/workspace/utils/menuVisibility.ts`

В `getFirstAvailableWorkspaceRoute` заменить аварийный fallback с `/workspace/profile` на `/workspace`.

## Критерии готовности

- [x] Пункт «Профиль» отсутствует в sidebar для `carcraft_employee`.
- [x] Прямой доступ по URL `/workspace/profile` для `carcraft_employee`
      перенаправляет на первый доступный раздел.
- [x] Для остальных ролей «Профиль» доступен без изменений.
- [x] E2E-проверка затронутого сценария в браузере (`tests/e2e/workspace/hide-employee-profile.spec.ts`).
