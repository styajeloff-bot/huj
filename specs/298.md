# Bitrix 22054: адреса анкеты и позиционные назначения дилеров

Bitrix: <https://carcraftpro.bitrix24.ru/workgroups/group/124/tasks/task/view/22054/>

## Контекст

При выборе компании анкета автоматически заполняла юридический адрес, а затем
без действия пользователя копировала его в фактический адрес и включала признак
«Фактический адрес совпадает с юридическим». Пользователь должен самостоятельно
решать, совпадают ли адреса.

После синхронизации с актуальной веткой `test` позиционные назначения дилера и
сотрудников уже реализованы задачей Bitrix 22106. Миграции
`090_application_vehicle_assignments.py` и
`092_repair_application_vehicle_assignments.py`, позиционные API и приоритет
латинских `mark_name`/`model_name` повторно не реализуются и не изменяются.

## Требования

- При выборе компании автоматически заполняется только юридический адрес.
- Пустой фактический адрес остаётся пустым, а признак совпадения адресов —
  выключенным, пока пользователь не включит его вручную.
- Уже введённый фактический адрес не перезаписывается при смене компании, если
  признак совпадения адресов выключен.
- После ручного включения признака фактический адрес копируется из юридического
  и продолжает синхронизироваться с ним.
- Загруженные из сохранённой анкеты значения фактического адреса сохраняются.
- Позиционные назначения разных дилеров остаются независимыми для каждой
  строки `application_vehicles`.
- Миграции `090` и `092`, backend-контракты назначений и отображение латинских
  названий транспорта не дублируются.

## Критерии готовности

- Выбор компании не меняет фактический адрес и не включает признак совпадения.
- Ручное включение признака копирует юридический адрес и поддерживает дальнейшую
  синхронизацию.
- Позиции двух дилеров возвращаются и изменяются независимо в существующем
  backend regression suite.
- В MR нет новых или изменённых Alembic-миграций.
- Единственный текстовый артефакт MR находится в `specs/298.md`; legacy-каталог
  `документация/` не возвращается.
- Перечисленные проверки проходят на актуальном `test`.
