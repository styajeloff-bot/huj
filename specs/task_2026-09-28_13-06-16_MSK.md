# Баннер ЛК: название компании в уведомлении об ограниченном доступе к заявкам

| Поле | Значение |
|------|----------|
| Bitrix | [22358](https://carcraftpro.bitrix24.ru/workgroups/group/124/tasks/task/view/22358/) |
| Ветка | `bugfix/22358` |
| Тип | bugfix |
| Область | frontend only — `frontend/pages/cabinet.vue` |

## Постановка

Залогиненный сотрудник, который зарегистрировался под существующей компанией, но ещё не получил доступ к заявкам от администратора (`can_view_applications = false`), видит в личном кабинете (`/cabinet`, вкладка «Мои заявки») предупреждающий баннер. Текст баннера не содержит названия компании, под которой сотрудник зарегистрировался, и ведёт на `/support` ссылкой.

## Требования

1. Заменить текст баннера на:

   > Доступ к заявкам ограничен. Обратитесь к администратору компании «{название компании}» или в поддержку, написав в чат внизу экрана.

2. Плейсхолдер `{название компании}` заполнять названием компании регистрации сотрудника из уже доступных данных auth (`authStore.userCompany` ← `active_company_name` / `company_name`).
3. Убрать ссылку на `/support`; вместо неё — упоминание чата внизу экрана в тексте.
4. Если название компании по какой-то причине отсутствует — показать тот же текст без пустых кавычек (фраза «администратору компании» без имени).
5. Не менять [`MyApplicationsPanel.vue`](frontend/features/applications/components/MyApplicationsPanel.vue) и backend.

## Планируемые изменения

- [`frontend/pages/cabinet.vue`](frontend/pages/cabinet.vue): обновить разметку баннера при `!authStore.canViewApplications` — интерполяция `authStore.userCompany`, новый текст без ссылки `/support`.

Backend и API не меняются: `GET /api/v1/auth/me` уже возвращает `active_company_name`.

## Критерии готовности

- [x] Сотрудник без `can_view_applications` на `/cabinet` видит баннер с названием компании регистрации.
- [x] В тексте нет ссылки на `/support`; указана поддержка через чат внизу экрана.
- [x] При пустом названии компании баннер не показывает пустые «».
- [x] `MyApplicationsPanel.vue` и backend не изменены.
- [x] Проверка в браузере (viewport ≥768px) и просмотр логов без ошибок по сценарию.
- [x] MR в ветку `test` со ссылкой на Bitrix 22358.
