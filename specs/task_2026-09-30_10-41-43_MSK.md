## 1. Постановка задачи

На странице `/workspace/storefronts` в панели управления витриной отображается кнопка «Конструктор витрины» со ссылкой вида:
```html
<NuxtLink :to="`/workspace/storefronts/${selected.id}/builder`">Конструктор витрины</NuxtLink>
```
При нажатии на эту кнопку клиентский роутер Vue Router выполняет переход по URL, ссылка помечается как активная (`router-link-active router-link-exact-active`, `aria-current="page"`), однако экран остаётся прежним (продолжает отображаться панель управления витринами со списком складов и настроек), а сам конструктор витрины не отображается.

### Причина
В Nuxt 3 наличие файла `pages/workspace/storefronts.vue` и вложенной директории `pages/workspace/storefronts/[id]/builder.vue` определяет иерархию вложенных маршрутов:
- Родительский маршрут: `/workspace/storefronts` (компонент `pages/workspace/storefronts.vue`)
- Дочерний маршрут: `/workspace/storefronts/:id/builder` (компонент `pages/workspace/storefronts/[id]/builder.vue`)

В компоненте `frontend/pages/workspace/storefronts.vue` жестко задан единственный тег `<AdminStorefrontsPanel />` без `<NuxtPage />`. Поэтому при переходе на дочерний маршрут Vue Router монтирует родительский компонент, но не находит точку вывода для дочернего роута и оставляет на экране `AdminStorefrontsPanel`.

---

## 2. Требования

1. При переходе по пути `/workspace/storefronts/:id/builder` (как при клике по кнопке «Конструктор витрины», так и при прямом открытии URL) должен корректно монтироваться и отображаться компонент конструктора `frontend/pages/workspace/storefronts/[id]/builder.vue`.
2. При нахождении на базовом пути `/workspace/storefronts` (с query-параметрами или без) должен отображаться компонент `AdminStorefrontsPanel`.
3. Сохранить авторизационные проверки (`auth`, `require-workspace`) и базовый лейаут (`workspace`).
4. При возврате из конструктора (по кнопке «Назад к списку витрин» в TopBar конструктора) должен осуществляться корректный возврат на `/workspace/storefronts` с отображением `AdminStorefrontsPanel`.

## 3. Планируемые изменения

1. **Обновление `frontend/pages/workspace/storefronts.vue`:**
   Реализовать условный рендеринг по аналогии с проверенным решением в `frontend/pages/workspace/leasing-applications.vue`:
   ```vue
   <template>
     <NuxtPage v-if="isChildRoute" />
     <AdminStorefrontsPanel v-else />
   </template>

   <script setup lang="ts">
   const AdminStorefrontsPanel = defineAsyncComponent(
     () => import('~/features/admin/storefronts/components/AdminStorefrontsPanel.vue'),
   )
   const route = useRoute()
   const isChildRoute = computed(() => route.path !== '/workspace/storefronts')

   definePageMeta({ layout: 'workspace', middleware: ['auth', 'require-workspace'] })
   </script>
   ```

2. **Проверка E2E:**
   Проверить сценарий открытия конструктора витрины через E2E / локальную сборку и убедиться, что конструктор монтируется при переходе по ссылке.
