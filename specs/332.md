# Настраиваемая видимость спецтехники в пользовательских витринах

## Контекст

В разделе администратора «Видимость разделов» для дополнительной витрины
пункт «Каталог транспортных средств и специальной техники» сейчас
принудительно выключен: интерфейс показывает «Всегда скрыт», frontend не
отображает спецтехнику под slug витрины, а backend запрещает сохранить
`special_equipment_catalog=true`.

Это противоречит актуальному требованию: спецтехника должна настраиваться для
каждой витрины так же, как остальные публичные разделы.

## Требования

- Для основной и каждой дополнительной витрины
  `public.special_equipment_catalog` независимо переключается администратором.
- Переключатель дополнительной витрины активен и не содержит текста о
  принудительной недоступности.
- Backend принимает как `true`, так и `false` для дополнительной витрины и
  возвращает сохранённое значение в её матрице видимости.
- Новая витрина копирует эффективную публичную матрицу основной витрины без
  принудительной подмены значения спецтехники.
- При включённом флаге пользователь внутри `/{slug}` видит ссылки и разделы
  спецтехники в контексте той же витрины; при выключенном флаге они скрыты.
- Существующие пользовательские витрины сохраняют текущее значение `false` до
  явного переключения администратором; массово включать раздел миграцией не
  требуется.

## Планируемые изменения

### Backend

- Удалить доменный запрет на включение спецтехники для дополнительной витрины.
- Убрать принудительный `false` из инициализации матриц новой витрины.
- Обновить domain/application/HTTP-регрессии: scoped PATCH с `true` успешен,
  изоляция матриц разных витрин сохраняется.
- Не изменять уже применённые исторические миграции; новая миграция не нужна,
  если схема БД не содержит отдельного ограничения на значение флага.

### Frontend

- Сделать переключатель спецтехники обычным доступным контролом для выбранной
  витрины.
- Удалить UI- и draft-state-хардкод, принудительно подменяющий значение на
  `false`.
- Использовать storefront-aware маршруты и матрицу видимости на главной, в
  header, избранном, корзине и личном кабинете.
- Добавить route alias для спецтехники под slug, если его ещё нет, сохранив
  глобальные API-маршруты изображений и каталога.

## Критерии готовности

- Администратор выбирает витрину FAW, включает спецтехнику, сохраняет и после
  повторной загрузки видит включённый переключатель.
- В `/faw` при включённом флаге отображаются предусмотренные ссылки и модули
  спецтехники; переходы не выбрасывают пользователя в корень `/`.
- При выключении флага спецтехника снова скрывается только в выбранной витрине.
- Настройка основной и других витрин не изменяется.
- Профильные backend/frontend тесты, полные обязательные проверки, сборка и
  локальная проверка приложения проходят без новых ошибок.
