# Заявка: количество техники и отображение цены

## Контекст

- Bitrix: https://carcraftpro.bitrix24.ru/workgroups/group/124/tasks/task/view/22120/
- Контрольная заявка: `3813002338-2108-001`.
- Контрольный дистрибьютор: `+76661234573`.

У дистрибьютора в общей карточке отображались две доступные позиции, хотя их
суммарное количество равно трём единицам, а сумма корректно считалась по трём
автомобилям. Тултип цены выходил за границы карточки у дистрибьютора и
администратора. В формах скидки и надбавки отсутствовали каталожная цена и
настройка её отображения, зафиксированные в приложенном ТЗ.

## Требования

- В сводке раздельно показывать число доступных позиций и сумму их `quantity`.
  Для контрольного scope ожидается `2 позиции · 3 единицы`, сумма остаётся
  `5 770 000 ₽`; область доступа дистрибьютора не расширяется.
- В формах скидки и надбавки показывать каталожную и итоговую цену через один
  общий неизменяемый компонент `PriceDisplayField` и checkbox
  `Отображать для клиента`.
- Каталожную и итоговую цену в карточке форматировать с разделителями тысяч и
  знаком `₽`, в том числе если API вернул денежное значение числом.
- Хранить независимые настройки для скидки и надбавки с default `true`.
- Эффективную видимость вычислять на backend:
  `show_catalog_price = discount_show_catalog_price AND markup_show_catalog_price`.
- При `true` показывать каталожную и итоговую цену с детальным тултипом.
- При `false` в карточке отдельной позиции показывать итоговую цену той же
  обычной строкой, что и у позиции без корректировок: без отдельного заголовка,
  иконки и тултипа.
- Текст `В итоговой сумме учтены скидки и надбавки по позициям заявки.` при
  скрытой каталожной цене показывать только в тултипе общей итоговой суммы.
- Ограничить тултипы границами карточки на desktop viewport от 768 px и связать
  триггеры с `role="tooltip"` для клавиатурной доступности.
- Для цены ТС, кнопки подсказки и тултипа использовать `z-index: auto`; у
  полноразмерной ссылки карточки остаётся существующий слой `z-10`.
- Одинаково применить контракт в кабинете дистрибьютора и администратора.

## Реализация

- Добавить миграцию `095` и два boolean-поля видимости в
  `application_vehicles`.
- При dealer action изменять только флаг соответствующего действия; отсутствие
  поля сохраняет текущее значение, непрайсовые действия флаги не меняют.
- Возвращать оба сохранённых флага и эффективный `show_catalog_price` в
  application/admin проекциях.
- Передавать checkbox в JSON и multipart запросах frontend.
- Обновить общую commerce-сводку, формы скидки/надбавки и admin mapping.

## Критерии готовности

- Контрольный distributor handler возвращает 2 позиции, 3 единицы и
  `5 770 000 ₽`.
- Оба checkbox сохраняются независимо, а backend-проекция использует `AND`.
- Скрытый режим не раскрывает каталожную цену, корректировки или комментарий и
  отображает позицию как обычную цену без заголовка, иконки и тултипа.
- Тултипы не выходят за карточку и доступны по клавиатуре.
- Профильные backend/frontend-тесты, линтеры, миграция и Docker build проходят.
- MR направлен только в `test` и содержит ссылку на Bitrix и результаты
  проверок.

## Результаты проверок

- Изменённые backend-тесты: `66 passed`; расширенный профиль: `73 passed`.
- Root cause follow-up: позиционная info-группа рендерилась независимо от
  `show_catalog_price`, поэтому скрытый режим удалял цену, но оставлял тултип.
- Root cause форматирования цены: числовые значения API не проходили строковую
  money-нормализацию, поэтому Vue выводил исходное число без разделителей и
  валюты.
